# 前端 UI 工程（Frontend UI Engineering）

## 概述

组件就近聚合、单一职责、状态管理选最简方案、遵循设计系统、WCAG 2.1 AA 可访问、移动优先响应式。

## 何时使用

- 构建/修改 UI 组件/页面、实现响应式布局
- 加交互/状态管理、修视觉或 UX 问题

## 组件架构

- 组件就近聚合（实现/测试/stories/hook/types 同目录）
- 优先组合而非配置；组件聚焦单一职责
- 分离容器（数据）与展示（渲染）

## 状态管理

- 选最简方案：useState → lifted → Context → URL → Server state → Global store
- 避免 prop drilling 超 3 层

## 避免"AI 审美"

- 忌：紫色/indigo 主色、过度渐变、rounded-2xl 一刀切、通用 hero、占位假文、过度 padding、通用卡片网格、重影
- 用一致间距比例、尊重标题层级、语义化色 token、对比度 4.5:1/3:1

## 可访问性（WCAG 2.1 AA）

- 键盘可访问、ARIA 标签、焦点管理（dialog 焦点陷阱）
- 空/错误/loading 状态都要处理
- 颜色不作唯一状态指示

## 响应式

- 移动优先，断点 320/768/1024/1440px
- 骨架屏（非 spinner）+ 乐观更新

## 红旗

- 组件超 200 行
- 内联样式或随意像素值
- 缺错误/加载/空状态
- 未做键盘测试
- 颜色作为唯一状态指示
- "AI 通用外观"

## 验证

- [ ] 无 console 错误
- [ ] 所有交互元素键盘可达
- [ ] 屏幕阅读器可传达结构与内容
- [ ] 四个断点可用；三种状态均已处理
- [ ] 遵循设计系统
- [ ] dev tools/axe-core 无可访问性警告
