防线体系（反追踪 + 体系攻击对端）

把「UA → IP隐藏 → 行为 → 指纹 → 频控/签名」化为一个系统会话；反追踪真实能力在此实测（隐藏 IP / egress 轮换 / XFF 混淆）。

防线分层（服务端权威 /api/system）
① UA 严检（拒脚本源）
② 来源 IP 必须隐藏（须经代理出口）
③ 行为分 0.1~0.6
④ 指纹一致性
⑤ IP 频控退避（连打即 429）
反追踪能力证明（实测观测）
直连 → 出口 127.0.0.1（真实 IP 暴露）
代理A → 出口 127.0.0.2（IP 已替换）
代理B → 出口 127.0.0.3（轮换，防一致性追踪）
XFF → 注入 203.0.113.7,198.51.100.4 混淆链
体系识破能力（/api/system/churn 一致性计数）
同身份 1 出口 → 一致
同身份 2 出口 → 可疑（轻度变化）
同身份 ≥3 出口 → 识破：IP 轮换/旋转
体系攻击语义：不隐藏 IP 的攻击者即在 L2 被 403 拦（来源直连、IP 未隐藏）；经代理隐藏后 5 层全过拿 SYS_FLAG。用 gongfang_system_attack 打 `/api/system` 复现。
