# 安得云荟 Android v1 · PC 端手动配置指南

| 项 | 值 |
| --- | --- |
| 用途 | 引导用户**手动**完成手机端所需的 PC 侧前提条件 |
| 适用范围 | v1（**不改动 Windows 桌面端任何代码**，纯手动配置） |
| 关联文档 | [`architecture-android-v1.md` §8.1](./architecture-android-v1.md)、设计规范 §4.5 |

> **前置条件**：确保 **安得云荟桌面版** 正在运行（桌面端本就常驻，作为「我的电脑」本体供手机组播发现 / 配对）。手机 App 与桌面端需处于**同一 Wi-Fi / 局域网**。

---

## 1. 让手机能连上你电脑上的 Ollama（必做）

手机无法访问 PC 上的 Ollama，绝大多数情况是 PC 端 Ollama 只绑定了 `127.0.0.1`（仅本机），手机必然连不上。需将其改为绑定 `0.0.0.0`。

### Windows（推荐：系统环境变量，永久生效）

1. 按下 `Win + R`，输入 `sysdm.cpl` 回车 →「高级」→「环境变量」。
2. 在「系统变量」或「用户变量」下点击「新建」：
   - 变量名：`OLLAMA_HOST`
   - 变量值：`0.0.0.0`
3. 确定保存后，**完全退出并重启 Ollama**（托盘图标退出，再重新启动 Ollama）。
4. 验证：在 PC 浏览器打开 `http://<本机局域网IP>:11434/api/tags`，能返回 JSON 即成功。

### 临时方式（命令行，重启失效）

```powershell
# PowerShell（仅当前会话有效，重启 Ollama 后需重设）
$env:OLLAMA_HOST="0.0.0.0"
# 然后在此窗口启动 Ollama
ollama serve
```

> ⚠️ 若 PC 有防火墙，请允许 Ollama（端口 `11434`）的**局域网入站**访问。

---

## 2. 读取桌面端 fingerprint（配对时双端确认用）

配对采用「组播发现 + fingerprint 双端确认」，无需账号密码。手机扫到设备后，会展示该设备 fingerprint 的**后 6 位**，你需要在 PC 端核对一致。

### 在哪里看桌面端 fingerprint

1. 打开 **安得云荟桌面版**。
2. 进入 **设置 → 关于 / 设备信息**（或配对相关入口），找到「本机 fingerprint」字段。
3. 记录其**后 6 位**字符。

> 手机端配对向导第 ② 步会展示同一 fingerprint 后 6 位。两端一致 → 确认配对；不一致 → 取消（防止连错设备）。fingerprint 仅用于校验，**不要向他人泄露完整值**。

---

## 3. 保持两端版本一致

- 手机版与 PC 桌面版均需为 **v1** 版本。
- 若协议版本不匹配，手机 App 会**在界面内给出明确提示**（而非静默失败），此时请将任一侧升级到匹配的 v1 版本。

---

## 4. 配置完成后的预期行为

| 步骤 | 手机端行为 |
| --- | --- |
| 配对成功 | 自动将 AI 算力端点改写为 `http://<已配对PC IP>:11434/v1`（**无需手填 IP**） |
| PC 已设 `OLLAMA_HOST=0.0.0.0` 且有模型 | 「算力来源条」显示「LOCAL_PC · 在线」，可直接跑本地模型 |
| PC 未设 / Ollama 未开 | 配对仍可完成，但 AI 对话会在探测阶段给出**精准指引**（提示去 PC 端设置 `OLLAMA_HOST`），并可一键降级到云端 |

---

> 本指南为 v1 的**手动配置**方案。后续版本可能提供 PC 端一键引导，但 v1 不改动桌面端代码。
